# FitFlys

FitFlys için Türkçe, statik ürün tanıtım sitesi.

## Dosyalar

- `index.html` — güncel ana sayfa
- `coming-soon.html` — GitHub'daki önceki “Çok yakında” ana sayfasının kopyası
- `style.css` — responsive görünüm ve hareketler
- `script.js` — sayfa etkileşimleri
- `assets/` — sayfada kullanılan görseller ve marka işareti
- `CNAME` — `fitflys.com` özel alan adı

Site derleme adımı olmadan çalışır. Yayın kaynağı olarak GitHub Pages'te `main` dalının kök klasörü kullanılır.
